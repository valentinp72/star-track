# Catalogue data

`catalog.json` is generated by [`scripts/build-catalog.mjs`](../../scripts/build-catalog.mjs)
from:

- the [HYG star database](https://codeberg.org/astronexus/hyg) 4.4
  (`data/hyg/CURRENT/hyg_v44.csv.gz`): stars to magnitude 5.0, proper motion
  applied to 2026.0;
- [OpenNGC](https://github.com/mattiaverga/OpenNGC) (`database_files/NGC.csv` and
  `addendum.csv`): Messier objects, and NGC/IC objects of magnitude 10 or brighter.

Both are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/),
and so is `catalog.json`. RA in hours and Dec in degrees, J2000 equinox.

To regenerate it, download the three files, then in `app/`:

```sh
node scripts/build-catalog.mjs hyg_v44.csv.gz NGC.csv addendum.csv
```
